# pdf-scan2reread

将扫描版或图片型 PDF 转换为可搜索、可选择、可复制的文字 PDF，同时尽量保持原始页面视觉版式。

## 核心原则

默认采用 `layout-preserving` 模式：保留原扫描页作为视觉背景，在原页面坐标叠加不可见但可搜索的 OCR 文字层。这样可以保持原始字号、行距、版心、双栏、页眉页脚、插图、表格和分页效果，避免将整本书错误地重新流式排版。

仅在用户明确接受版式变化时使用 `text-reflow` 模式，将 OCR 文本重建为纯文字流式 PDF，并明确说明其与原版布局可能不同。

## 适用场景

- 扫描书、扫描论文、历史档案和图片型 PDF；
- 需要全文搜索、复制、索引或辅助阅读；
- 需要保留原始页面外观和分页；
- 中文、英文或中英混排文档的 OCR 与版面还原。

## 使用方式

直接请求：

```text
使用 pdf-scan2reread，把这个扫描 PDF 转成版面保持、可搜索和可复制的文字 PDF。
```

如果确实需要纯文字重排：

```text
使用 pdf-scan2reread，以 text-reflow 模式转换；我接受版面和分页变化。
```

## 输出

默认文件名格式：`<原文件名>_可搜索版_版面保持.pdf`。输出报告会列出 OCR 引擎和语言、坐标校准、页面尺寸、低置信度/图像保留区域，以及搜索复制和视觉回归验证结果。
