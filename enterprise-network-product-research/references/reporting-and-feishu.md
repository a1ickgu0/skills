# 报告与飞书交付

## 报告是分析层，不是另一个事实库

从已审查的 JSON 快照生成 report/report.md。默认包含：结论摘要；范围/默认值/方法；产品组合及能力分布；关键端口、容量、PoE 与配置分析；重点差异；重要未知及冲突的影响；来源及附件索引。只保留对当前任务有用的章节，不生成空壳。

每项关键结论使用稳定编号，并关联 claim IDs；比较必须对齐地区、时点、产品形态、配置和单位。解释系列差异时区分证据支持的能力与厂商定位表述，不将来源不足转换成“产品不具备”。未定义用户需求和权重，不输出综合排名或推荐最优。

小任务可在答复中交付，无须全套报告。全景研究至少选择一张真正解释能力或配置关系的图；若数据不足以支持图形，明确说明而非编造。不要仅为图文并茂制造无意义图表。

## 默认全景图组合：A＋B

用户已选择A＋B作为默认产品研究图形组合，不以接口数量条形图代替全景。

**A 产品组合定位图**：采用[PNG出图样例](panorama_masked.png) / [SVG出图样例](panorama_masked.svg) 的信息语法：顶部标题/范围/图例，按速率档位及有依据的应用定位组织横向泳道，同层排列统一尺寸的SKU卡片。卡片包含型号/系列、接入+上联组合、交换容量、PoE/电源及定位或配置限制；容量突出但不把整机与线卡混成排名。卡片头颜色仅编码已证实的版本/代际/类别，有图例；缺版本证据时改为产品形态类别，禁止编造版本或代际。当前参考是独立生成的8款Aruba研究输入示例，数据及来源定位见[示例数据](panorama-example.json)；非完整目录、非官方背书、非全部参数重新核验。文件名masked仅为兼容既有引用，不代表其内容仍为原私有图脱敏版。泳道高度随卡片行数变化，列数随版面调整，不能退化成三个独立大卡片或纯参数表。参考文件只供版式使用，不能作厂商事实来源；路径不存在时沿用上述结构而非假称已读取。

按已证实的系列、固定/模块化形态组织产品，明确整机、机框、线卡及依赖关系。可增加有证据的接入/汇聚/核心/数据中心定位；没有依据时不用定位标签。若使用坐标，必须采用可核验的速率/配置等技术维度，禁止主观“能力高低”排名。机框依赖单独表达，不把线卡当同层整机。局部样例标明覆盖范围，不补画未核实全产品线。

**B 型号能力矩阵**：行是SKU，列是决策相关能力（形态、接入口、上联/高速口、PoE预算、扩展、关键限制）；单元格来自claim及配置。默认与选配、数量与介质条件分开；已知零写0，未知写待核，不适用写不适用。整机与线卡分区。每张图均有中文标题/图注、数据版本、来源关联及等价文本表。

全景研究默认交付A、B两图的SVG及同源PNG；数据不足时缩小到样例定位并说明缺口，不为填图编造产品。A验证结构和关系，B逐格核对字段/配置；不得只验证文件存在就声称语义正确。具体任务要求优先。

## 同能力SKU差异优先机制（出图前必做）

全景图必须回答“为何有多个相同端口/容量的SKU”，不能把SKU编号作为唯一可见差异。先按子平台/完整接口组合/容量/配置口径建立同能力组，再比较：子系列及硬件代际、气流、电源AC/DC与数量、风扇数量/交付、TAA/认证、PoE与预算、软件许可、区域/包装及裸机/套件。只展示有依据的属性，禁止把未标TAA解释为非TAA，把“2 PSU”默认解释成AC，或把Front-to-Back直接等同Port-to-Power而无厂商方向定义。

每组先提取共同能力，卡片优先给出组内变化项；差异行不得被公共备注或长接口描述挤掉/截断。建议同平台相邻排序，气流与电源/认证使用独立文字标签（颜色仅辅助）。多SKU可增加变体小矩阵：行=电源，列=气流，TAA分组；原SKU仍可逐个追溯，不合并真实订货型号。

例如8325P的32×40/100G、6.4T仅是共同底座；8个SKU若由气流×AC/DC×TAA标注形成变体，必须在图上呈现这些轴。名称只写2 PSU的旧8325不能擅自归到AC格；同接口变体若仍无法解释，标“差异未识别，待核”，不编造代际/性能提升。硬件/认证/交付差异都可能影响采购，不能仅关注速率。

JSON保存variant/differentiators判断及来源、提取方法和限制；CSV模板不扩列，差异摘要写现有备注，明细用独立sku-differences.csv。B矩阵应另有差异视图而非只重复速率列。验收：同能力组内存在已知差异时，去掉SKU后卡片仍可区分；同名能力但配置不同的代表SKU必须测试气流、电源、认证文本实际进入SVG，而非仅存在数据文件。所有差异都未知时允许相同卡片，但必须公开缺口。

## 紧凑排版与字体约束

生成或重做图文视觉前，若环境提供frontend-design、frontend-ui-engineering技能，必须加载并应用其排版与工程检查，不只按固定坐标堆文字。保留参考图的泳道/卡片语法，以技术产品目录为目标，不做大留白演示页。

- 字体：中文优先思源黑体/Noto Sans CJK SC、苹方、Hiragino Sans GB等清晰无衬线；SKU/数字与中文协调。SVG声明可替代font-family；PNG渲染显式指定本机有效字体文件，不默认Arial Unicode作为最终审美方案，不嵌入无授权商业字体。安装或名称存在不代表渲染成功。
- 字阶：标题约26–30px、分区18–22px、SKU20–23px、主信息14–17px、辅助12–14px（按约1280–1680px源图）；采用有限字阶与常规/中等/加粗三级，禁止全部等大等重。实际缩放至文档宽度后检查可读性，不能靠继续缩小字体塞信息。
- 密度：4px间距尺度，卡片内边距12–16px，同层间距12–16px，正文行距约1.35–1.5。公共能力/来源限制放组标题或脚注一次，不在每个格子重复。内容决定画布高度，不预留半屏空白；圆角4–8px、无重阴影。
- 变体矩阵：行列已表达气流/电源/认证时，格内优先仅放SKU或独有差异；不要重复全部行列标签和“同能力不同配置”等空话。保留有实质风险的脚注。
- 卡片：固定的头部、接口摘要、容量、关键差异、次要条件基线；差异不可截断。长接口摘要最多两行，按词/语义断行，避免切开SKU/速率；超长时另附完整文本。不能以紧凑为由隐藏未知或认证限定。
- 颜色：源于参考和统一语义token，主文字对比至少4.5:1、辅助文字仍清晰；不用颜色单独表达差异，不引入装饰渐变/大量彩色块。静态文档图可固定浅色画布，不能默认透明背景。

验收必须实际渲染：检查密集页、最长名称页、同能力专项矩阵的中文/数字、文本边界、重叠及阅读顺序。记录检查过的页，不将资源存在测试说成全图视觉验收。压缩前后记录尺寸，确认减少的是重复和空白，而非关键字段。SVG保持文字可选、无脚本/外部依赖；PNG与SVG同源。

## 图形选择与依据

- 能力矩阵：展示产品能力和限制；未知单独编码，不画成零。
- 接入/上联组合：区分固定、可选和互斥，避免各速率简单堆叠。
- 端口组、Combo、breakout 示意：标注并发条件和物理/逻辑口径。
- 机框—线卡—电源关系：表达支持关系，不用边的存在暗示任意组合都兼容。
- 生命周期时间线：只画可证实日期，估计与时间区间明显区别。

图表使用相同数据版本，图注写明单位、配置、筛选条件及限制，保留用于作图的数据和生成方式。横向比较不能混合标配、最大和未知配置。颜色之外用标签、形状或线型区分状态；正文复述关键结论，不让信息只存在图中。若运行环境有图表/设计技能，生成图前加载适用技能。

## SVG 源图与兼容图

交付 SVG 源文件，设置 viewBox、明确尺寸和 title/desc，字体采用可替代系统字体。禁止脚本、外部字体/图片依赖及 foreignObject；不将关键文字转成无法提取的路径。并从同一源图生成足够清晰的 PNG，记录渲染工具和尺寸，检查文字溢出、裁剪及缩小后可读性。

SVG 是可编辑源图，不是飞书原生可编辑图，也不等于所有导入链路都支持直接嵌入。没有渲染工具时交付 SVG 并明确 PNG 未生成，不把不完整资源包标成导入就绪。

## 飞书友好包

正文使用标准 Markdown 标题、短段落、简单表格、明确图注和来源编号；避免依赖 HTML、复杂合并单元格、交互内容或仅有 Mermaid 代码的图。宽参数表作为附件，正文只放决策相关列。

manifest.json 包含：

- `dataset_id`、`revision`、`report_path`、`data_path`、`export_paths`；
- `conclusions`：结论 id、正文定位、claim_ids，区分事实/推导/假设；
- `figures`：id、caption、svg_path、png_path（未生成用 null）、正文插入位置、claim_ids、作图数据路径、renderer、dimensions；
- `delivery_status`：本地校验结果及 `feishu_import`（`not_tested` / `passed` / `failed`），已测试时附实际链路和结果。

所有路径相对交付根目录，不包含绝对路径或 `..` 路径穿越。manifest 不能把未测试的导入标成 passed。

实际导入前读取当前飞书文档/云盘技能，按具体链路选择 PNG 插图、SVG 附件或经验证支持的 SVG 方式；本地 Markdown 图片路径不保证自动上传。导入后核对正文层级、图片顺序/尺寸、中文字体、图注、表格与来源链接。若未授权或无认证，不执行远程写入，明确“本地包已生成，飞书导入未验证”。
