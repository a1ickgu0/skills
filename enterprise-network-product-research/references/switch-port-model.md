# 交换机端口与电源模型

- 先记录机身或线卡的物理业务口、连接器、支持速率、数量、复用组及配置条件。管理口和堆叠口是否计入由用户口径或字段说明决定，不能隐式混合。
- 多速率接口可出现在多个速率字段；不同列不能相加。Combo RJ45/SFP 可能在电口和光口栏重复，但同组不能同时使用，明确标记。不要把连接器数量直接等同于可并发端口数。
- 一分多 breakout 的逻辑接口数量与物理笼位分开，记录线缆、软件和端口组限制。SFP/SFP+/SFP28/SFP56 或 QSFP 外形本身不能证明该 SKU 支持某低速、某高速或某 breakout 模式。
- 型号名称只在其列出的接口完整且可核对时用于推断不存在的速率；名称可省略管理、上联、可选模块或隐藏接口。高于已知最高速率的零值也须考虑扩展模块和其他接口。
- 模块化机框表示“随线卡配置”；预配套件标明标配和扩展；可选模块不与标配混同。多速率/分组可能降低可同时启用的数量；最大或下限需标明配置及公式依据。
- GE/10G 电口默认指机身固定 RJ45 业务口；若使用可插拔 RJ45 模块需要单列或注明，按用户口径调整。PoE 口数、PoE 等级、供电预算和电源配置分别列出，不从 PoE 名称推定预算。

平面字段默认分别标识连接器数量、可并发业务接口数量、breakout 逻辑接口数量，并为速率能力指定配置和并发模式。以“20 个独立 RJ45 + 4 组 RJ45/SFP Combo”为纯示意：连接器为 28，可并发业务接口为 24；GE 电口能力 24、GE 光口能力 4，不代表可以同时启用 28 个接口。此示意不证明任何具体 SKU 的规格。

验收实例可使用 Combo 光电复用、4 个 SFP56 多速率、带可选上联模块的固定设备、预配置机框、线卡分组和 breakout；实例只用于验证思路，不能套用到未证实的其他 SKU。
